## 📖 Описание

Этот проект демонстрирует принципы работы автоматизированных систем отправки запросов, интеграции API и обработки большого количества обращений.

В проекте реализованы:

* API-сервис для обработки запросов
* Работа с базой данных
* Поддержка Docker для удобного развёртывания
* Конфигурация через переменные окружения

---

## 🚀 Возможности

* REST API интерфейс
* Поддержка Docker и Docker Compose
* Скрипты инициализации базы данных
* Гибкая настройка через `.env`
* Пример whitelist-конфигурации

---

## 📁 Структура проекта

```
sms-bomb-master/
│
├── api.py                # Основной API сервер
├── bomb.py               # Основная логика
├── db.py                 # Работа с базой данных
├── requirements.txt      # Зависимости Python
├── Dockerfile            # Конфигурация Docker
├── docker-compose.yml    # Оркестрация контейнеров
├── init.sql              # Схема базы данных
├── .env                  # Переменные окружения
└── whitelist.json        # Лист исключений
```

## ⚙️ Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/AxellorWave/sms-bomb.git
cd sms-bomb
```

### 2. Настройка переменных окружения

```bash
mv .env.example .env
mv whitelistexample.json whitelist.json
```

Отредактируйте файлы `.env` `whitelist.json` под свои нужды.

---

## 🐳 Запуск через Docker (рекомендуется)

```bash
docker-compose up -d --build
```

---

## 🧪 Запуск локально

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск сервера

```bash
python bomb.py
```

---

## 🗄️ Настройка базы данных

* Схема базы данных находится в `init.sql`
* При использовании Docker база инициализируется автоматически
